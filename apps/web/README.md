# Web app

Target stack: Next.js + TypeScript + Tailwind + shadcn/ui + Tiptap.

Initial screens:
- `/login`
- `/new-workspace`
- `/w/[workspace]/home`
- `/w/[workspace]/browse/[...path]`
- `/w/[workspace]/document/[nodeId]`
- `/w/[workspace]/search?q=`
- `/w/[workspace]/settings/members`

UI principle: one navigation tree for folders, documents and files.
